# Web LED Control

## Task 2 - Control LED via Web

### Project Description
This project creates a simple web interface to control an LED using ON and OFF buttons.

### Steps
1. Created a web page for LED control.
2. Added LED ON and LED OFF buttons using HTML.
3. Added JavaScript functions to change the LED status.
4. Added CSS to style the web interface.
5. Published the project using GitHub Pages.
6. Tested the buttons and verified that the LED status changes between ON and OFF.

### Files
- index.html
- style.css

### Result
The web interface works successfully, and the LED status can be switched between ON and OFF.
